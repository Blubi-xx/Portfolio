Mi entorno de trabajo

¿Qué ocurre cuando escribo una URL?

Cuando escribo una dirección web en el navegador, se realizan varios pasos hasta que aparece la página.

  1. Escribo la URL en el navegador.
  2. El DNS busca la dirección IP asociada al dominio.
  3. El navegador se conecta con el servidor web.
  4. El navegador solicita los recursos de la página mediante HTTP o HTTPS.
  5. El servidor responde enviando archivos como HTML, CSS, JavaScript e imágenes.
  6. El navegador interpreta los archivos y muestra la página web.

Mis herramientas de trabajo

  • Visual Studio Code: editor que utilizo para escribir y organizar el código.
  • Extensiones: añaden funciones al editor y facilitan algunas tareas de desarrollo.
  • Live Server: permite abrir la página en el navegador mediante un servidor local y ver los cambios al guardar.
  • Git: sistema de control de versiones que permite registrar los cambios realizados en el proyecto.
  • GitHub: plataforma donde puedo alojar mis repositorios, compartir mi código y consultar el historial de cambios.
